# E-Commerce Sales Analysis 📊

## Project Overview

This project focuses on analysing an E-Commerce Superstore dataset using Python and Exploratory Data Analysis (EDA).

The objective is to discover sales trends, understand business performance, identify profitable product categories and explore regional sales patterns.

Kaggle – Superstore Dataset

https://www.kaggle.com/datasets/vivek468/superstore-dataset-final

## Project Workflow

1. Dataset loading and exploration
2. Data cleaning and preprocessing
3. Missing value and duplicate checks
4. Exploratory Data Analysis
5. Sales and profit analysis
6. Data visualization
7. Business insights and conclusions

## Key Findings

* Total records: 9,994
* Total sales: $2,297,200.86
* Total profit: $286,397.02
* Overall profit margin: 12.47%
* Best-performing category: Technology
* Highest sales region: West
* Highest aggregated sales month: November
* Missing values: 0
* Duplicate records: 0
